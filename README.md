# TEMPO PULSE

Дневник тренировок и питания. На экране «Сегодня» собраны показатели дня, а перед тренировкой можно выбрать, где заниматься.

![TEMPO PULSE — Сводка дня](assets/social-preview.jpg)

<a href="https://tempo-fitness-pwa.pages.dev/"><img src="https://raw.githubusercontent.com/mrjakeball/mrjakeball/main/assets/buttons/app-ru.svg" height="36" alt="Открыть приложение"></a>

Опубликованная PWA · Публичная витрина приватного проекта  
React 19 · TypeScript · Dexie · WebAuthn

## Что происходит с записями

**В течение дня.** В дневнике можно вести питание, воду и сон, открывать программы тренировок и отслеживать изменения показателей.

**На устройстве.** Основные записи хранятся локально через Dexie. Это позволяет возвращаться к дневнику без постоянного подключения. Приложение поддерживает вход по PIN и через WebAuthn.

## От сводки дня к тренировке

**[Сегодня](assets/screen-home-mobile.jpg)** · Вверху виден прогресс по дневным целям. Ниже расположена карточка следующей тренировки.

**[Условия занятия](assets/screen-workout-mobile.jpg)** · Перед началом программа предлагает выбрать место тренировки. На снимке видно этот шаг до перехода к упражнениям.
