## 🎯 Задача проекта

Собрать тренировки, питание, сон, воду и динамику прогресса в одном мобильном интерфейсе, которым удобно пользоваться каждый день.

Основные сценарии не должны зависеть от постоянного соединения с сервером.

## 📌 Коротко

| | |
| :--- | :--- |
| 📱 **Формат** | Мобильное web-приложение / PWA |

## 🧭 Основной сценарий

- 🏋️ программы тренировок и выбор условий занятия;
- 🍽️ дневник питания;
- 😴 учёт сна;
- 💧 контроль воды;
- 📈 отслеживание прогресса;
- 📱 установка приложения как PWA.

## ⚙️ Что здесь было интересно реализовать

### 💾 Local-first

Основные пользовательские данные хранятся локально, поэтому приложение остаётся полезным даже без постоянной сети.

### 🔐 WebAuthn

Для входа используется современный механизм аутентификации без необходимости строить классическую парольную схему.

### ♻️ Состояние и восстановление

Важная часть проекта — предсказуемое сохранение, восстановление и резервное копирование пользовательского состояния.

## 🧪 На что обращаю внимание

- мобильная адаптация;
- сохранность локальных данных;
- восстановление после обновлений;
- понятные состояния загрузки и ошибок;
- стабильная работа основных пользовательских сценариев.

> ℹ️ **О репозитории:** это публичная витрина проекта. Приватные пользовательские данные и исходный код приложения здесь не публикуются.
